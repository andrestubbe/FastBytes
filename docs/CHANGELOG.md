## [v0.1.0] - 2026-05-16

### Added
- Initial JNI implementation with AVX2 support
- Automated compile scripts for Windows
- SIMD-accelerated copy, fill, find, and hash operations
- First public release via JitPack
- Full integration with FastCore library loader
